# One core, three personalities

The core (notes, sync, Markdown, checklists, properties) is shared. Each platform dresses and behaves like itself.

| | Android | Linux desktop | Web |
|---|---|---|---|
| Moving around | swipe gestures; panels follow the finger; floating bottom bar | sidebar + contents panel side by side; keyboard first (Ctrl+P, Alt+Z…) | like desktop, with browser keys |
| Tasks | swipe to tick or delete (you choose), ⋯ menu | hover tools: add subtask, edit, delete, ⋯ | same as desktop |
| Settings | a list of categories that slides to a page, big rows | full page: tabs on the left, cards on the right | same as desktop |
| Properties | folded by default, label above value | open by default, grid | open by default |
| Extras | home-screen checklist widget, keep-alive sync, Material You colours | system colours, notes folder, native selection | install as an app (PWA, planned) |

Rule: when something is added, ask "what would feel native here?" for each column before copying it across.
