Fonts that ship inside the app (all free, SIL Open Font License 1.1):

- Noto Naskh Arabic UI v2.017 — https://github.com/notofonts/arabic (OFL-Noto.txt)
- JetBrains Mono Nerd Font Mono — JetBrains Mono (https://github.com/JetBrains/JetBrainsMono) patched by Nerd Fonts (https://github.com/ryanoasis/nerd-fonts). The "Mono" variant keeps icons one cell wide, which is right for code (not the proportional "Propo" variant).
- Roboto — from the @fontsource/roboto package.

They are converted to woff2 only; the glyphs are unchanged.
